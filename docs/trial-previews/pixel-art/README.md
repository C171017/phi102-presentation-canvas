# P1 Trial pixel-art set

The handheld-style Trial uses a 256 × 192 pixel grid for each image, with solid color ramps, sparse checkerboard dithering, and nearest-neighbor display. The supplied screenshots informed the scale and palette. Simone’s silhouette, the zodiac wheel, the Gavel, and the supporting cast use Ink Ocean designs.

The prosecutor sleeps through his mother’s interruption, then the prosecution desk returns when he wakes. The final ruling shows the cracked courtroom.
